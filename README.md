Здесь размещены все исходные файлы проекта.

Для запуска сервера потребуется установить [Python](https://www.python.org/downloads/).

Для установки библиотеки Flask используется менеджер пакетов Python (в командной строке): `pip install Flask`. Зависимости Flask установятся вместе с библиотекой.

можно запустить сервер (app.py) с помощью команды `py app.py`, редактируя хост и порт внутри файла app.py.
Но официальный способ запуска производится с помощью команды: `flask --app app run --host="хост" --port=3306 –-debug` (без отладки `--no-debug`)
